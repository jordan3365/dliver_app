======================================================
📱 플러터 기사앱 (Flutter Driver App) 구현 기능 상세 명세
======================================================

1. 로그인 및 사용자 세션 관리 (Auth & Session)
  - 사번 및 비밀번호를 통한 안전한 로그인 처리
  - SharedPreferences를 활용한 오프라인 상태에서의 세션 정보 유지
  - 앱 재시작 시 자동으로 이전 세션을 복구하여 자동 로그인 지원

2. 스마트 배송 관리 및 현황판 (Delivery Management)
  - 할당된 코스별 "오늘 배송 목록"을 실시간으로 서버에서 불러와 표시
  - 배송 완료 건과 미완료 건을 구분할 수 있는 직관적인 필터링 및 UI 제공
  - 전체 할당 건수 대비 완료율을 상단에 실시간 프로그레스 바(게이지)로 시각화
  - 배송처 클릭 시 상세 주소, 연락처, 특이사항(메모) 등의 정보 제공 팝업
  - 배송 완료 버튼 원클릭으로 서버에 상태 즉시 업데이트
  - 배송처 도착 후 현장 사진을 촬영하거나 갤러리에서 선택하여 앱 내에 등록 (image_picker 연동)
  - 배송처 전화번호 터치 시 즉시 전화 걸기 기능 지원

3. 실시간 내비게이션 및 자동화 연동 (Navigation & Automation)
  - url_launcher 패키지를 활용한 카카오맵(앱) 딥링크 자동 실행 지원
  - 현재 위치 기준 배송처 및 출발지(HQ)까지의 직선거리 계산 및 하단 표시 기능
  - 사용자의 스마트폰에 카카오맵 앱이 설치되지 않은 경우, 카카오맵 웹 브라우저로 안전하게 우회(Fallback)하는 기능 탑재
  - 배송처 반경 30m 이내 접근 시 카카오내비게이션 자동 종료 및 기사앱 복귀 (배송 완료 처리는 기사가 직접 수동으로 하여 정확도 향상)
  - 수동 배송 완료 처리 시 서버 동기화를 백그라운드로 전환하고 대기 시간 없이 즉각 다음 배송지로 길안내를 실행해 체감 처리 속도를 극대화
  - 모든 배송 완료 후 본사 반경 30m 이내 복귀 시 네비게이션 자동 종료 및 앱 복귀, "오늘 하루도 고생하셨습니다." 안내 후 자동 로그아웃 처리

4. 정밀 GPS 추적 및 백그라운드 관제 (GPS & Tracking)
  - geolocator 라이브러리를 통해 앱이 백그라운드 상태이거나 화면이 꺼져 있어도 실시간 위치(위/경도)를 수집 및 송신
  - 3m 이상 위치 이동 시 자동으로 서버 전송을 수행하며, 10초 이상 응답이 없을 시 강제로 위치를 업데이트하는 타이머 폴백 적용
  - 배터리 소모를 방지하기 위해 3초 간격의 중복 전송 방지 필터 로직 적용
  - 배송 완료 버튼을 누르는 순간, 완료 위치 정보의 신뢰도를 높이기 위해 해당 좌표를 서버로 1회 강제 전송
  - 앱바 상단에 GPS 추적 기능을 수동으로 끄고 켤 수 있는 제어 토글 제공

5. 오프라인 데이터 무결점 동기화 (Offline-first Synchronization)
  - 지하 주차장 등 5G/LTE 네트워크가 완전히 끊긴 음영 지역 대응 알고리즘 적용
  - 오프라인 상태에서 배송을 완료하면 해당 내역을 기기 내부(SharedPreferences)에 임시로 안전하게 저장
  - 지상으로 이동하여 인터넷 연결이 감지되는 즉시, 큐(Queue)에 쌓인 미전송 완료 데이터들을 서버로 누락 없이 일괄 백그라운드 동기화

6. 맞춤형 공지사항 및 팝업 시스템 (Notice System)
  - 관리자가 등록한 전체 또는 소속 코스별 맞춤 공지사항을 수신
  - 새로운 공지사항(수신 메시지)이 있을 경우 스마트폰 상단 푸쉬 알림(Push Notification)으로 즉시 표출되며, 확인한 공지는 다시 뜨지 않도록 처리

7. 내장 지도 화면 (In-App Map View)
  - flutter_map (OpenStreetMap)을 연동하여 카카오맵을 열지 않고도 앱 내에서 기사의 현재 위치와 전체 배송처 핀을 한눈에 조망할 수 있는 지도 탭 제공


======================================================
💻 관리자앱 (Admin App / Web Dashboard) 구현 기능 상세 명세
======================================================

1. 실시간 물류 관제 대시보드 (Real-time Tracking Dashboard)
  - 플러터 기사앱과 연동된 카카오 네비게이션 GPS 좌표를 기준으로 운행 중인 전체 차량의 위치를 초 단위로 폴링하여 실시간 경로(선) 및 마커로 지도에 표시
  - 특정 차량 마커에 [LIVE] 뱃지를 표출하여 기사앱과 서버 간의 통신 상태가 정상인지 관리자가 실시간 확인 가능
  - 화면 우측 패널에 각 코스별 총 배송 건수 및 진행률(%)을 직관적인 게이지 형태로 리스트업

2. AI 기반 정밀 예상 도착 시간(ETA) 산출 (AI ETA Prediction)
  - 단순한 직선거리 계산이 아닌, OSRM(오픈소스 라우팅 엔진)의 실시간 교통상황과 차량별 남은 배송처 개수(배송 하차 소요 시간)를 종합적으로 분석
  - 각 차량별로 본사(HQ)로 최종 복귀하는 분 단위의 정확한 "예상 도착 시간(ETA)"을 대시보드에 표기

3. 🚨 본사 하차장 대기 자동 경보 시스템 및 복귀 상태 표시 (HQ Arrival Alert & Status)
  - 기사가 모든 배송을 완료하고 본사로 복귀 중, 시스템이 계산한 ETA가 '10분 이내'로 진입 시 즉각적인 경보 발동
  - 관리자 화면 한가운데 강력한 붉은색 네온사인 애니메이션 팝업창 표출
  - 동시에 컴퓨터 스피커를 통해 "도착 10분 전입니다" 음성 방송(TTS)과 함께 싸이렌 경보음이 재생되어 하차 인력 즉시 투입 지원
  - 차량이 최종적으로 본사(HQ)에 도착 시 우측 차량 관제 요약 패널에 "본사도착" 및 "업무 종료" 상태로 즉각 업데이트 표시

4. 스마트 공지 발송 및 기사 원격 제어 (Messaging & Control)
  - 관리자 대시보드에서 전체 운행 기사 또는 특정 코스(예: 1호차)를 선택하여 다이렉트 팝업 메시지 발송
  - 이미지 파일(Ctrl+V 등)을 포함한 공지사항 작성이 가능하여 직관적인 업무 전달 지원
  - 운행을 잊고 미출발 상태에 있는 기사를 관리자 권한으로 [출발 시키기]를 눌러 강제 업무 시작 처리 가능

5. AI 라우팅 기반 코스 자동 배차 시스템 (AI Routing & Dispatch)
  - 신규 배송처(거래처) 등록 시 주소를 입력하면 지오코딩 엔진이 즉각적으로 위도와 경도를 추출해 핀을 생성
  - 미배정 배송처들을 K-Means 군집화(Clustering) 알고리즘으로 지역별 덩어리로 묶음
  - 이후 묶인 그룹 내에서 외판원 문제(TSP) 알고리즘을 수행하여 최단 동선을 도출, 특정 기사(코스)에게 자동으로 최적 코스를 배차

6. 독립 메모리 기반 배송 시뮬레이터 (Simulation Mode)
  - 실시간 관제 메인 지도와 충돌하지 않도록 메모리가 100% 분리된 별도의 배송 시뮬레이션 전용 뷰 제공
  - 특정 기사(코스)의 경로를 미리 그려보고, 가상 마커가 실제 차량처럼 경로를 따라 이동하는 것을 시뮬레이션하여 동선 효율성 검증 및 교육용으로 활용 가능
